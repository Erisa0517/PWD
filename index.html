A. Profil Saya

Halo! Nama saya Erisa Safitri. Saya adalah mahasiswa aktif Program Studi Sistem Informasi di Fakultas Ilmu Komputer, Universitas Dian Nuswantoro. Saya memiliki ketertarikan dalam bidang analisis sistem, pengembangan aplikasi web, pengelolaan basis data, serta pemanfaatan teknologi informasi.

Sebagai mahasiswa Sistem Informasi, saya senang mempelajari berbagai hal baru yang berkaitan dengan teknologi informasi. Saya juga terus berusaha mengembangkan kemampuan melalui tugas, proyek perkuliahan, dan kegiatan akademik.

Website ini dibuat sebagai salah satu latihan dalam memahami struktur dasar HTML5 sekaligus sebagai media untuk memperkenalkan profil, pendidikan, keahlian, proyek, dan aktivitas akademik saya.
